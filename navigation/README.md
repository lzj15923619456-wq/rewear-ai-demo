# REWEAR 底部弹性导航

此目录接入用户提供的 React Bits RubberSegment 和 DepthCarousel JavaScript + CSS 源码，使用 React、React DOM、motion 与 GSAP。底部导航、顶部三步选择和穿搭卡片轮播由 React 渲染，其余页面沿用原有 JavaScript。

## 修改与构建

在本目录执行 `npm ci`，然后执行 `npm run build`。构建输出为 `../dist/navigation.js` 与 `../dist/navigation.css`，页面已引用这两个文件。使用已构建的 demo 无需安装依赖。

- `RubberSegment.jsx` / `RubberSegment.css`：弹性滑块、惯性拖动、边缘回弹、键盘操作及减少动态效果适配。
- `DepthCarousel.jsx` / `DepthCarousel.css`：用户提供的 GSAP 透视轮播源码与移动端适配。
- `WakeSlider.jsx` / `WakeSlider.css`：用户提供的 Motion 波浪条；新增只读进度模式，随真实阶段推进。
- `workflow-progress.css`：四个节点、完整中文标签和黑白灰进度样式。
- `outfit-carousel.css`：完整穿搭卡片的灰度表面、动态高度与操作按钮留白。
- `navigation.jsx`：衣柜、搭配、记录与三步中英文标签及页面状态绑定。
- `navigation.css`：黑白灰配色，宽度占屏幕 61% 的悬浮胶囊；高度为 `clamp(56px, 16.4vw, 78px)`，390px 屏幕约为 64px 高。
- `build.mjs`：将 React、motion 与 GSAP 一起打包为本地浏览器脚本，不依赖 CDN。

项目适配：测量使用未缩放的布局像素，确保样机缩放后的拖动坐标正确；补充 Enter / 空格触发的键盘激活；异步字体测量在组件销毁后停止。页面重绘保留同一个导航 DOM 节点及 React 根，防止页面切换中断滑块动画。

圆形高亮使用新增的可选 `thumbWidth` 属性（此处为 `"circle"`，按轨道高度减去两侧 inset 自动计算直径，也接受数字），仅缩小居中的滑块目标宽度，不缩小完整选项的点击范围。没有传此属性时仍按原组件填满选项宽度。导航下间距 10px，另加运行时底部安全区。外围容器透明、绝对定位且不拦截触摸，只有黑色胶囊接受输入；内容延伸到导航后方，末尾滚动留白保护操作按钮。带固定操作栏的步骤单独预留导航空间。拖动和弹性伸展沿用原组件行为。

2026-10-04 验证：已有三个导航入口、双向拖动、方向键、End 和 Enter 切换验证。最新悬浮改版再验证了拖动到记录及方向键返回搭配。390px 预览导航约为 238 × 64px；320px 窄屏无横向溢出，导航约为 195 × 56px，三个点击区均为 44px 高。滚动到录入页末尾后继续按钮完整露出；风格页固定操作栏底边为 460px，导航上边为 468px，两者没有交叠。

这是网页 React 组件。后续原生微信小程序迁移需在自定义 tabBar 中实现对应的状态、触摸事件和动画；这些 JSX 与 motion 浏览器代码不能直接导入 WXML / WXSS。布局基准继续使用 `../WECHAT-LAYOUT.md`。

顶部三步选择：连续 60px 高的玻璃胶囊，标签为 ITEMS / STYLE / PREFERENCES。使用可选 `thumbSurface` 渲染独立圆弧高光、透明表面与渐变折光边缘，跟随同一组弹性动画边缘。点击、拖动及方向键沿用底部导航的动画；`onChange` 返回 `false` 可拒绝步骤切换，校验失败时选中块留在原步骤。页面重绘同时保留顶部 React 根。已验证选单品→选风格→说偏好→返回选单品，方向键切换，以及无单品时拒绝跳步；390px 和 320px 下标签不横向溢出。质感采用灰度反光，维持全应用黑白灰配色。

穿搭轮播：使用 DepthCarousel 的连续 position、translateZ、rotateY、亮度、模糊和遮色动画，700ms / power3.out。当前参数 depth=180、spread=55、tilt=22、perspective=1400。使用 `renderItem` 承载完整穿搭 HTML（沿用原有转义），`fullWidth` 保持卡片接近屏宽，仅比容器窄 20px 以露出后方层次；ResizeObserver 测量展开内容并更新舞台高度。`index` 和 ref.goTo 绑定现有页码与箭头。禁止自动播放和循环，保留六套后的更多卡，每次补充三套至十二套。

交互适配：样机缩放转换为布局坐标；横向拖动与触控板滑动切换，纵向滚轮继续读页面；每次拖动至多切换一套。拖动后的点击被抑制，分析、选中、展开说明与更多按钮独立操作，非当前卡片内容 inert。动画进行时短暂阻止卡片点击；快速反向切换可接续当前位置。退出结果页时销毁 GSAP 动画与事件，结果页重绘保留 React 根。当前卡片、匹配度、需求和已录入单品沿用原有数据逻辑。

轮播验证：构建通过；样机中拖动、箭头、方向键、详细分析、选这套及返回原卡片正常。第六套后可进入更多卡并补充三套。展开匹配说明后舞台高度随内容更新。320 × 568 窄屏容器宽 292px、当前卡宽 272px，页面宽度仍为 320px，无横向溢出。
