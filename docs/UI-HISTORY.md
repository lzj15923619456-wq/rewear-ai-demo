# 再穿 REWEAR — 交互 Demo

2026-10-04。以手机为主的中文网页演示，用于验证“让闲置单品真正被穿起来”的产品流程，尚非微信小程序。

2026-10-04 视觉更新：手机为主要使用场景。根据用户最新纠正，只参考“择星”小程序的设计与交互规范，配色统一采用黑白灰：浅灰底、白色卡片、黑色按钮与灰色选中状态。录入分为“选单品 → 选风格 → 说偏好”三步，内容区域独立滚动。所有屏幕共用手机单列布局；宽屏仅居中展示，最大宽度 480px。详细基线见 `DESIGN.md`。

场景与风格更新：6 张真实场景图片（日常通勤、周末出门、朋友聚会、约会、旅行、看展）以两行三列呈现，支持多选；12 张真实黑西装穿搭照片采用双列长帖子流，每张保留原文章署名和来源。底部固定显示选择数量与继续按钮，选择场景与风格后无需重建图片列表。多项偏好会带入下一步、预设方案说明、保存计划和导出清单。详细来源见 `真实图片来源.md`。

## 体验

本机多单品更新：录入页按上衣、裤装、鞋类纵向排列，每类可添加一件照片，任意录入 1～3 件即可继续。支持分别更换、编辑名称和移除。风格页、方案、衣柜核对、保存及导出清单会带入全部已录入单品，并将其标为已有；调整方案时保留这些单品，修改录入内容后重新查看方案。上传的上衣不会被自动认定为需要内搭的外套，内搭仅列作可选。

当前使用十二套真实照片的预设参考池，首轮展示六套，没有接入 AI 图像识别或多单品匹配服务。已录入照片只保留于页面内存；保存计划只写入名称、品类与清单，不保存图片。旧计划仍可查看。

双击本目录 `start-demo.cmd`，访问 http://127.0.0.1:4174/ 。无需安装前端依赖。

首次打开先显示 REWEAR 品牌进入页，点击“进入”，再点击“体验示例”并继续，使用黑色宽松西装走通流程：场景与图片式风格选择 → 六套重叠卡片参考 → 翻卡动画、规则评分与差异说明 → 末尾增加更多方案 → 选择方案 → 衣柜替换 → 按预算选购 → 可选组合预览 → 调整不满意部分 → 保存穿搭计划 → 实际穿着反馈。

## 当前可操作

- 单品图片本地预览、格式与大小验证、编辑单品名称。
- 场景、排斥效果、风格、变化程度与选填个人信息。
- 首轮六套不同方向的真实照片卡片，可继续增加至十二套；每套保留来源和具体差异。
- 放宽条件的说明与示例顺序变化；详情分析、快捷追问。
- 核对已有衣物、按示例评估替换、同步购买缺口。
- 每件预算、选购标准、候选商品位置演示、淘宝搜索入口。
- 锁定满意单品后调整其他部分，变更后的清单与核对状态同步。
- 模特参考比较与本人照片上传入口，明确不输出虚构试穿效果。
- 保存、导出清单，穿了/未穿原因与满意度反馈；浏览器本地存储。
- 两个渐进增强 WebMCP 工具：读取演示状态、选择预设方案。

## 演示边界

搭配、替换和追问采用预设示例；没有接入 AI 图像识别、跨平台实时搜图、自由问答、真实商品推荐或 AI 试穿服务。上传其他衣服仍以黑色西装展示，不声称完成了匹配。个人条件和自由文本记录于当前会话并明确提示尚未分析。

所有照片只保留于当前页面内存，不上传服务器、不写入持久存储。计划、衣物描述和反馈保存在当前浏览器 localStorage；不跨设备同步。使用系统中文无衬线字体，不依赖外部字体加载。

真实编辑照片取自 Who What Wear，页面内已标署名，来源信息位于 `dist/assets/reference-photos.json`。未核验商业再分发许可，正式上线前应换成用户授权/平台授权或自有内容。
