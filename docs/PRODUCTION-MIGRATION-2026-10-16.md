# 生产迁移与验证记录（2026-10-16）

## 迁移范围

生产从旧 Coze 两工作流调用迁移为六个固定角色的 OpenAI Chat Completions 兼容调用。评测数据、评分、封存目录和指纹未修改，也未复制进公开仓库。

最小代码差异：

- 单品识别与参考图核对拆为 `item`、`reference` 两个视觉角色，分别使用千问和 Kimi。
- 搭配切换为千问；主理人、衣柜和复盘使用 DeepSeek Flash。
- 使用封存的 P1 提示词；单品识别附加最终风险约束。
- 千问请求显式发送 `enable_thinking=false`；DeepSeek／Kimi沿用各自非思考参数。
- 衣柜修改返回“需要确认／参考不足”时不再强制生成一套方案，不覆盖原方案、锁定项或记忆；网页直接展示追问。
- Render Blueprint 改为六角色直连配置，所有 Key 仍只由 Render Environment 注入。
