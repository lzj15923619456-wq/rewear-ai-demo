# REWEAR AI 接入与验收

## 当前状态（2026-10-09）

网页和后端已接通已部署的 Coze 工作流。缺失/错误 Token 被拒绝，正确 Token 的 payload/result 协议验证通过。真实识图、人工确认、推荐、追问、保留单品调整、计划保存、反馈及访客隔离的主链路已通过；现有三组 Node 测试和五组 Python 保护测试也通过。使用新的授权图库重新验收时，当前通勤/久走条件返回2套参考方案；不会强行补成6套。验收范围和限制见 docs/AI-ACCEPTANCE.md。GitHub 源码已发布，公开在线 Demo 尚未部署。

## 请求的原理

网页通过同源 HTTP API 发 JSON。后端验证访客会话、图片与要求，再使用私密凭证请求 Coze。工作流校验请求，调用模型并返回 JSON。后端再次检查引用图片是否存在、所有录入衣物是否保留，最后向网页返回方案。模型负责建议；身份、所有权、图片来源、保存和结果校验由后端负责。

一个工作流按 payload.action 分发 analyze、recommend、revise、answer。请求外层为 payload，响应外层为 result。每个有效业务请求最多调用一次模型；无效 action 不调用模型。

## 本地配置

需要 Node.js 24.x（验收版本24.19.0）和 pnpm 11.25.0。根目录安装依赖后，将 .env.example 复制成私有 .env；配置现有 Coze 项目部署页给出的基础域名和凭证。识别与规划共用同一个工作流，两组配置可以使用相同值。服务端自动请求基础域名下的 /run。凭证不得放入网页、GitHub、截图或压缩包。

运行 npm start，打开 http://127.0.0.1:4174/iphone-preview.html 。Windows 也可使用 start.ps1。修改配置之后重启；/api/status 中 Ready 为真只说明配置存在，不证明凭证有效。未配置时真实识别和生成会如实报错，不拿预设方案冒充 AI。

上传图片需用户确认发送给 Coze。后端只解码 JPEG/PNG/WEBP，最大 8 MB、2500 万像素，缩到 1400px 内并去除 EXIF。识别不确定的材质留空，用户核对并确认后才允许推荐。示例黑西装为人工标注。

## 图库与匹配边界

AI 推荐当前只使用8张已核对来源和许可的真实照片：Commons 2张、Pexels 4张、Unsplash 2张。文件与人工核对描述见 references-new.json。Maegan Tintari 使用 CC BY 2.0；Jamie / petitepanoply 使用 CC BY-SA 2.0；其他照片分别遵循来源网站许可。作者与许可在AI方案详情展示。旧编辑参考已从AI索引排除，公开版已用授权摄影替换旧样式选项和欢迎页图片，来源见 dist/assets/photo-credits.json。局部照明确注明未展示的鞋和包，不能将建议写成照片事实。

当前图库覆盖女性黑西装，其他外套和男性服装不强行匹配。用户可保留裤装和鞋类，但参考照片不保证与全部衣物相同；不足六套时明确返回不足，不重复凑数、不捏造图片地址。照片未生成或合成试穿；模型只接收人工核对的参考描述。

匹配百分比为标签规则分：风格 40、场景 30、尝试程度 20、避开效果 10。它不是模型置信度、合身概率或全部要求的验证结果。自由文字要求由模型规划，尺码与舒适度仍需实际试穿。

## 在线运行

服务需要 Node.js 24、HTTPS 和持久磁盘；设置实际 PUBLIC_ORIGIN、监听 HOST/PORT 和持久 DATA_DIR。SQLite 暂按单实例运行；静态 GitHub Pages 无法单独运行此后端。

衣物照片和计划保存于服务端，匿名 Cookie 分隔访客，不等同微信登录。清除 Cookie 后无法恢复原匿名会话。本版本尚无账号找回或跨设备同步。

公开体验限额为每会话每天 12 次、每连接 IP 每天 24 次、全站每天 60 次。它与用户解除的开发积分预算分别控制。代理部署可能把多个访客视为同一个连接 IP；上线须依服务商可信代理规则处理，不盲信客户端自报地址。
